<h2>一、先算需求：数量还是地区覆盖</h2>
<p>数量容易算，覆盖容易被忽略。业务要的是同一城市的多个地址，还是分散在多个国家，两种需求对应的报价能差一倍以上。</p>
<p>把账号分布摊开看一遍：哪个国家占大头，哪个城市必须固定，哪些只是备用。清单列出来，采购单才有依据。</p>
<p>预留两成冗余就够了。一次买太多，闲置地址照样计费，续费时还得为它们做取舍。</p>
<h2>二、询价时要问清的六件事</h2>

<p>只回一句住宅地址的供应商，多半是把共享池拆开卖。追问细节显得较真，却能省下后面几个月的返工。</p>

<h2>三、批量开通的实际流程</h2>
<p>正规流程是先签合同或下单试用，再提交地址清单，供应商按城市分配，最后交付账号与配置。每一步都要有书面记录。</p>
<p>提交清单时把用途写清楚。用途含糊的订单容易被拒，或者被塞进质量较差的地址段。</p>
<h3>批量开通失败的常见原因</h3>
<p>常见三种：目标城市库存不足、提交信息与实际用途不符、付款方式触发风控。提前问库存能避开第一种。</p>
<p>开通后拿到的是配置信息，不是可用地址。要自己跑一遍验证，确认出口地址和归属都符合约定。</p>
<h2>四、到货验收不要省</h2>
<p>验收至少查四项：出口地址是否与清单一致、ASN是否为住宅运营商、上下行速率、连续二十四小时的掉线次数。</p>
<h3>抽样比例怎么定</h3>
<p>抽样比例按批量走，十个以内全测，上百个抽三成。发现系统性偏差就整批退回，别一个个补。</p>
<p>验收记录要留档，最好附上测试时间和工具版本。后面出现争议，这份记录是唯一能拿出来的证据。</p>

<h2>五、计费与续费口径</h2>
<p>月租按自然月还是按三十天，差别不小。按自然月计费时，月中开通也收整月，批量采购要算进成本。</p>
<p>流量计费要问清计费方向。只算下行和上下行都算，同样用量能差出三四成。</p>
<p>续费提醒要提前设。批量地址到期时间集中，漏续一天可能整批停用，恢复还要重新配置。</p>
<h2>六、一家供应商还是多家</h2>
<p>单一供应商省事，价格也好谈，但库存和线路都押在一家，出问题没有备份。</p>
<p>两家按比例分，主供应商七成、备选三成，切换成本低，议价时也有参照，适合多数团队。</p>
<p>供应商数量不必多。三家以上，对账、验收和沟通的工作量，很容易把省下的钱吃掉。</p>
<h2>常见问答</h2>
<h3>批量开通一般要多久？</h3>
<p>答：库存充足时当天到两三天，需要按城市调配时一周左右。跨境线路还要留出配置和交付的时间。</p>
<h3>一次买几十个能便宜多少？</h3>
<p>答：常见是标价的八到九折，量再大要谈年度框架。折扣通常绑定预付和长约，算总成本时要把占用资金计入。</p>
<h3>家庭IP和住宅IP是一回事吗？</h3>
<p>答：多数语境下指同一种资源，区别在供应商的叫法。有的把家庭宽带单独列为更高一档，实际要看ASN和接入方式。</p>
<h3>供应商说独享，怎么验证？</h3>
<p>答：连续多时段查出口地址和ASN，看是否稳定不变；再在并发时观察速率是否被其他流量挤占。单次测试证明不了独享。</p>
